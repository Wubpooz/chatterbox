### Option B: Extract from Existing Model

If you already have the Chatterbox model downloaded locally:

```python
from huggingface_hub import snapshot_download
import json

# Download model files (only needed once)
ckpt_dir = snapshot_download(repo_id="ResembleAI/chatterbox")

# Find the vocabulary file
vocab_file = f"{ckpt_dir}/grapheme_mtl_merged_expanded_v1.json"

# Load and extend
with open(vocab_file, 'r') as f:
    vocab_json = json.load(f)

vocab_dict = vocab_json['model']['vocab']
max_id = max(vocab_dict.values())
vocab_dict['[mt]'] = max_id + 1

# Save extended vocabulary
with open('grapheme_mtl_merged_expanded_v2.json', 'w') as f:
    json.dump(vocab_json, f, ensure_ascii=False, indent=2)
```
